# 会员提醒：Android 真机验收清单

资产扩展 P6 的真机验收（spec §7：权限、手机重启后通知仍在、点击跳转）。**在真机上照着做之前，先问过用户**：
这些步骤会在用户的手机上建测试卡、改设置、退出再登录、重启手机。测试卡会同步到全家：持有人一定选自己（见准备第 2 步），
不然家里其他人的首页、会员权益 tab 也会出现它，装了新版的手机还可能收到它的提醒。整张清单不需要连电脑；
标了「可选」的核对才用 adb。

每天最多一条会员提醒：今天那条弹过之后，再把时间改晚也不会弹第二条（这是预期）。下面要「再弹一条」的步骤，
都先退出登录再登录一次：退出登录会撤掉所有会员提醒、清掉本机记着的「今天已经提醒过」，提醒时间也回到 09:00。

## 准备

1. 手机上装好带 P6 改动的家账（debug 或 release 都行），用一个家庭账号登录，记好密码（后面要退出再登录）。
2. 「资产 › 会员权益」里新建一张测试卡：平台随便选，名称「提醒测试卡」，到期日选**明天**；「更多」里**持有人选自己**
   （默认是「全家共用」，会打扰家里其他人），续费价填 30、周期选「每月」、续费选「不确定」。
   月付卡到期前 1 天要提醒，所以今天就有一条。
3. 「我的 › 会员提醒」：确认「每日摘要通知」开着。时间先不改，下面第二节再改。

## 一、通知权限（Android 13 及以上）

1. 新装的家账：「会员提醒」页有一行「通知权限 · 未允许」，点「允许」→ 弹出系统权限框 → 选**不允许** →
   页面仍是「未允许」，副标题写着「拒绝过的话，点「允许」会打开系统的通知设置」；首页和「要处理」照常提醒。
2. 再点「允许」→ 又弹出系统权限框 → 再选**不允许**（到这里系统就不再弹框了）。
3. 第三次点「允许」：不再弹框，直接打开系统里家账的通知设置页；在那里打开通知，回到家账变成「已允许」。
4. 到系统设置里把家账的通知整个关掉（Android 13 及以上，这一下等于收回通知权限），回到「会员提醒」页：变回「未允许」。
   点「允许」：弹出系统权限框，或者直接跳到系统的通知设置页，**两种都算通过**；打开后回来变成「已允许」。
5. 系统设置 › 应用 › 家账 › 通知里能看到单独的「会员提醒」类别，和「自动记账」分开，可以单独开关。
6. Android 12 及更早的手机：通知开着时不显示「通知权限」这一行（系统不需要申请）；把通知关掉后这一行会出现，
   点「允许」去系统的通知设置。

## 二、到点弹出、一天只弹一条、点击跳转

1. 「提醒时间」改成比现在晚 3 分钟。页面下方「接下来」的第一条应该是「会员权益 · 提醒测试卡 快到期」，
   日期写「今天」、钟点是刚改的时间。按 Home 回桌面（家账留在后台，**不要**划掉）。
   到点后通知栏出现「会员权益 · 提醒测试卡 快到期」，正文「X月X日到期 · 还有 1 天」，小图标是一个礼物。
   用的是非精确闹钟，可能晚几分钟；开着省电模式时可能更晚。**先别点它。**
2. 一天只弹一条：从桌面图标打开家账，进「会员提醒」把时间再改晚 3 分钟。通知栏里那条还在（没被撤掉）；
   「接下来」里不再有「今天」；到了新时间也不再弹第二条。
3. 家账在后台时点通知：按 Home 回桌面，点通知栏里那条 → 打开家账，停在「资产 › 会员权益」，顶上选中「本期」和「我」，
   「要处理」里有这张卡。
4. 冷启动：「我的」里退出登录再登录（理由见开头），「提醒时间」改到 3 分钟后，回到桌面，从最近任务里把家账划掉
   （**不要**用「强行停止」，那会清掉系统里所有的闹钟）。到点点通知：家账冷启动后同样停在会员权益的「本期 · 我」。
5. 退出登录：再退出登录再登录一次、把时间改到 3 分钟后，等通知弹出来、**先别点**；然后「我的」里退出登录：
   这条从通知栏消失（预期：上一家的卡名不留在通知栏里），之后不再收到会员提醒。从桌面打开家账落到登录页，不闪退。
   最后重新登录，接着做第三节。

## 三、手机重启后通知仍在

1. 小米 / 红米 / POCO（MIUI、澎湃）：先在「会员提醒」页点「允许自启动（MIUI）› 去设置」，把家账的自启动打开。
   不开的话手机收不到开机广播，重启后排好的提醒会丢。
2. 今天已经弹过会员提醒的话，先退出登录再登录一次。把提醒时间设成大约 15 分钟后，确认「接下来」里是今天这个时刻。
3. 重启手机，重启后**不要打开家账**。
4. 到点后通知照样弹出；点开同样落到会员权益的「本期 · 我」。
5. （可选，要连电脑）`adb shell dumpsys alarm | grep -B2 -A6 com.famledger.app`：重启后能看到家账排的闹钟。

## 四、收尾

1. 把「提醒测试卡」删掉，回到「会员提醒」页：「接下来」里不再有它；到了原来的时间不再弹。
   家里别的设备同步一次（下拉刷新或重新打开）之后也就没有它了。
2. 关掉「每日摘要通知」之后不再弹；「接下来」写「已关闭」。重新打开恢复。
3. 把提醒时间改回原来的（默认 09:00；中途退出登录过的话已经回到 09:00）。
4. 网页版打开「我的 › 会员提醒」：只显示「网页版不能推送」。

## 已知限制

- 非精确闹钟（inexactAllowWhileIdle）、不申请精确闹钟权限：通知可能比设定时间晚几分钟，Doze 时可能晚几十分钟。
  晚到的那条不会因为中途打开家账被撤掉。
- 每天最多一条：今天那条到过点（弹过，或者还在路上）之后，把时间改晚不会再弹；改到比现在早，今天也不再弹。
- 通知内容在排的那一刻算好。别的设备改了数据、这台手机又一直没打开家账时，要等下次打开同步后才更新。
- 「强行停止」会让 Android 清掉家账的全部闹钟，要等下次打开家账才重新排。
- 提醒设置只存在这台手机上，退出登录后回到默认（开着、09:00）。
